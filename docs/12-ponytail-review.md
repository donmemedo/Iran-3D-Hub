## Kept on purpose (looks heavy, is a requirement)

- backend/app/security.py:L23-29 scrypt with a 4-slot BoundedSemaphore, plus dummy_verify: closes the login timing oracle (232.7 ms vs 6.8 ms) and the hash-flood memory DoS.
- backend/app/ratelimit.py:L33-35 `_MAX_KEYS` prune and routers/auth.py:L40-53 per-account failure budget (`over`/`hit`/`forget`): bound memory under key rotation and stop distributed guessing without letting anyone lock a victim out.
- backend/app/middleware.py:L29-55 BodyLimit with the counting receive: enforces the 64 KB JSON and 60 MB upload caps for chunked or lying Content-Length bodies, which the declared-length check alone misses.
- backend/app/routers/quotes.py:L22,L119-124 `_parse_slots` and geometry.py MAX_TRIANGLES (500k): cap CPU and memory of the pure-Python mesh parse (at most 2 parallel parses).
- backend/app/security.py:L87-106 signed quote plus `typ` claim checks (L104, L120): the client cannot alter price. The derived key and the typ check overlap, but both are cheap defense against token-type confusion, so keep them.
- backend/app/config.py:L40-49 `_guard`: refuses to boot on a missing, short or known-default JWT_SECRET outside DEV.
- backend/app/routers/orders.py:L98-107 `_transition` compare-and-set, L148-152 IntegrityError path on unique(order_id), and L154-156 atomic rating update: close the double-advance, double-review and read-modify-write races.
- backend/app/main.py:L58-62 custom RequestValidationError handler: the default echoes the offending input, which can be megabytes.
- frontend/next.config.ts CSP and header set, and middleware.py SecureHeaders: security-header findings; 'unsafe-inline' is documented at next.config.ts:L14-21.
- frontend/src/app/login/page.tsx:L16-17 `safeNext`: open-redirect guard.
- frontend/src/components/StlViewer.tsx:L39-43,L51 header triangle-count pre-check and MAX_VERTICES: client-side allocation DoS guard.
- frontend/public/sw.js `/api/` bypass and the `basic` check in `cacheable`: authenticated responses are never cached.
- frontend/src/components/SwRegister.tsx dev-unregister branch: `dev` and `start` both bind :3000, so a leftover prod worker would serve stale /_next/static chunks over dev edits.
- frontend/src/app/globals.css skip-link, :focus-visible ring, prefers-reduced-motion, reduced-transparency and prefers-contrast blocks, plus the aria attributes on the Header, FAQ, dropzone and filters: accessibility requirements, not bloat.
- frontend/src/app/page.tsx:L17 and quote/page.tsx:L15 `dynamic()` imports: take three.js out of the initial bundle (167 kB home first-load).
- docker-compose.yml x-hardened (read_only, cap_drop, no-new-privileges, tmpfs, pids and mem limits) and both Dockerfiles' non-root user and pip removal in each stage: container-hardening findings.
